MSMG Toolkit PS7 - altered version notice
==========================================

This software is an ALTERED VERSION of the MSMG Toolkit. It is an unofficial,
independent rewrite in PowerShell 7 that supports Windows 11 only. It is not the
original software and it is not affiliated with or endorsed by MSMG.

Changes compared to MSMG Toolkit 13.7 (see CHANGELOG.md for details):
  - The batch script (Toolkit.cmd) was replaced by a newly written PowerShell 7 module.
  - Support for Windows 7, 8.1, 10 and Windows Server up to 2022 was removed.
  - The bundled third-party binaries (DISM copies, NSudo, 7-Zip, ToolkitHelper,
    ResourceHacker, dvdburn, esddecrypt, PSFExtractor) were removed; the toolkit uses the
    tools of the Windows 11 host instead. wimlib 1.14.5 is bundled (Bin\x64) under its own
    license, see Bin\LICENSES\wimlib.txt - it is NOT covered by the license below.

The original copyright notice and permission notice follow and apply to this
altered version as well.
